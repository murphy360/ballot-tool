# Ballot tool

Two Cursor canvases for the November 3, 2026 general election in the City of Twinsburg, Summit County, Ohio.

- `canvases/ballot-guide.tsx` is a neutral guide to every race and issue on that ballot.
- `canvases/alignment-quiz.tsx` is an alignment quiz. You answer topic questions, and it scores the candidates.

Both files are Cursor canvas source: TSX that imports components from `grok/canvas`. Paste either file into a Cursor canvas to view it.

These are neutral research notes, not endorsements. Check them against official sources before you rely on them.
